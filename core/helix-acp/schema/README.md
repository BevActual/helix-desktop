`v1.json` is the Agent Client Protocol's published schema for protocol version 1, copied unchanged from
https://github.com/agentclientprotocol/agent-client-protocol (`schema/v1/schema.json`), which is Apache-2.0 licensed
(Copyright the Agent Client Protocol authors). It is used only by the tests, to check that what this crate sends and
reads has the shape the protocol publishes.

Every plugin declares the oldest API level it requires with `plugin_api` in `plugin.toml`. API levels are cumulative:
use the oldest level that includes every capability your plugin needs to keep it compatible with as many Helix
versions as possible.

<PluginApiTable />

Helix currently supports plugin API levels <PluginApiRange />. A plugin version declaring a level outside that range
cannot run.

Raising a plugin's level therefore drops it from every Helix below it. A source repo can keep those users covered by
publishing older revisions in its catalog: Helix then installs the newest revision of the plugin its own API range
allows, labels it in the store as an older version, and moves the user up to the newest one once they upgrade Helix.
See [keeping older Helix versions supported](/noctalia/plugins/development/workflow/#keeping-older-helix-versions-supported).

Shows the hottest coding-CLI quota (or a running llama.cpp / vLLM server, or the selected Ollama model, when no quota is hotter) and opens the [AI](/noctalia/control-center/#ai) Control Center tab on click. The glyph follows the hottest CLI; the percent turns red at **Usage Warning**.

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| `max_length` | number | `80` | Maximum length for the status text |

```toml
[widget.ai]
max_length = 120
```

```sh
noctalia msg ai-usage-status
noctalia msg ai-usage-refresh
noctalia msg ai-usage-ollama-start
noctalia msg ai-usage-ollama-stop
noctalia msg ai-usage-ollama-model llama3.2:latest
noctalia msg ai-usage-ollama-pull llama3.2
noctalia msg ai-usage-ollama-cancel
noctalia msg ai-usage-ollama-delete llama3.2:latest
```

Home is a glance at this machine, not a second Control Center. Pins are optional actions at the bottom of Home, in the order you list them. They render as leftover grouped rows (icon and label), not Control Center tiles. Size and icon-only labels do not apply. Add only what you reach for; the default list is empty.

Configure the list in TOML or from **Home → header gear**. To reorder in place, press a pin and drag it up or down: it lifts, the neighbours slide aside to show the slot, and releasing writes the new order to `control_center.shortcuts`. A plain click still runs the pin's action.

```toml
[[control_center.shortcuts]]
type = "wifi"

[[control_center.shortcuts]]
type = "bluetooth"

[[control_center.shortcuts]]
type = "nightlight"

[[control_center.shortcuts]]
type = "notification"
```

When no `[[control_center.shortcuts]]` entries are defined, Home has no pin list. Existing configs that already list shortcuts keep them.

## Entry Fields

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `type` | string | *required* | Shortcut type from the list below |
| `size` | string | `"small"` | Ignored on Home. Kept for older configs. |

## Dynamic Shortcuts

Toggle shortcuts show an active/inactive visual state. `power_profile`, `weather`, and `keyboard_layout` display dynamic labels such as the current power profile, temperature, or keyboard layout.

`weather` is available only when `[weather].enabled = true`. `system` is available only when `[system.monitor].enabled = true`. `screen_time` is available only when `[shell].screen_time_enabled = true`.

`ai` shows the hottest remaining quota across detected AI CLIs (`claude`, `codex`, `gemini`, `qwen`), or a running llama.cpp / vLLM server / Ollama status. The tile lights up when a quota is at or above the usage warning threshold.

`screen_recorder` is a built-in shortcut for the shell recorder (`screen-record-toggle`). While a recording is running the tile highlights, switches to a stop icon, and shows elapsed time. `screen_replay` does the same for the built-in replay buffer (`screen-record-replay-toggle`) and needs `gpu-screen-recorder`. Right-click saves the last N seconds without stopping the buffer; if the buffer is not running, right-click opens Screen Record. Record and replay tiles disable each other while the other is running. The official [`helix/screen_recorder` plugin](/helix/plugins/official-plugins/#screen_recorder) still exposes its own shortcut as `helix/screen_recorder:toggle` when enabled.

`tailscale` toggles this machine's Tailscale connection. Right-click opens the Tailscale tab. The tile is disabled when the `tailscale` CLI is not installed. The community plugin's bar widget and panel remain available.

`firewall` opens the Firewall tab. The tile highlights when panic mode is on.

`printers` opens the Printers tab. The tile highlights when a printer is printing or has queued jobs.

`privacy` opens the Privacy tab. The tile highlights when an app is using the microphone, camera, or screen share.

The Home tab displays a row of shortcut buttons at the bottom. Up to 6 shortcuts are shown. You can configure the list in TOML or edit it from **Settings -> Control Center**.

```toml
[[control_center.shortcuts]]
type = "wifi"

[[control_center.shortcuts]]
type = "bluetooth"

[[control_center.shortcuts]]
type = "nightlight"

[[control_center.shortcuts]]
type = "notification"

[[control_center.shortcuts]]
type = "wallpaper"

[[control_center.shortcuts]]
type = "session"
```

When no `[[control_center.shortcuts]]` entries are defined, the default set is: `wifi`, `bluetooth`, `caffeine`, `nightlight`, `notification`, `power_profile`.
Set `shortcuts = []` under `[control_center]` to hide all Home shortcut buttons.

Use `show_shortcut_labels` under `[control_center]` to show or hide the text under each shortcut icon (default `true`). When labels are off, the icons scale with the shortcut cell size, which is useful at narrower Control Center widths.

```toml
[control_center]
show_shortcut_labels = false
```

## Entry Fields

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `type` | string | *required* | Shortcut type from the list below |

| `bluetooth` | Bluetooth | Toggle adapter on/off | Open bluetooth tab |

| `dark_mode` | Dark Mode | Toggle light/dark theme | - |
| `caffeine` | Caffeine | Toggle idle/sleep prevention | - |

| `mic_mute` | Microphone | Toggle mic mute | Open audio tab |
| `power_profile` | Current profile | Cycle power profile | Open system tab |
| `media` | Media | Play/Pause active player | Open media tab |

| `system` | System | Open system tab | Open system tab |

## Dynamic Shortcuts

Toggle shortcuts show an active/inactive visual state. `power_profile`, `weather`, and `keyboard_layout` display dynamic labels such as the current power profile, temperature, or keyboard layout.

`weather` is available only when `[weather].enabled = true`. `system` is available only when `[system.monitor].enabled = true`. `screen_time` is available only when `[shell].screen_time_enabled = true`.

`screen_recorder` is a built-in shortcut for the shell recorder (`screen-record-toggle`). While a recording is running the tile highlights, switches to a stop icon, and shows elapsed time. The official [`noctalia/screen_recorder` plugin](/noctalia/plugins/official-plugins/#screen_recorder) still exposes its own shortcut as `noctalia/screen_recorder:toggle` when enabled, including replay-buffer actions.

`tailscale` toggles this machine's Tailscale connection. Right-click opens the Tailscale tab. The tile is disabled when the `tailscale` CLI is not installed. The community plugin's bar widget and panel remain available.

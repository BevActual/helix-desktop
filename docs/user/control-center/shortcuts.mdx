The Home tab displays shortcut buttons beside the media and clock cards. Related shortcuts group into glass islands (Wi-Fi with Bluetooth, Do Not Disturb with Caffeine, and so on). Up to 6 shortcuts are shown. You can configure the list in TOML or edit it from **Settings -> Control Center**.

```toml
[[control_center.shortcuts]]
type = "wifi"

[[control_center.shortcuts]]
type = "bluetooth"

[[control_center.shortcuts]]
type = "nightlight"

[[control_center.shortcuts]]
type = "notification"

[[control_center.shortcuts]]
type = "wallpaper"

[[control_center.shortcuts]]
type = "session"
```

When no `[[control_center.shortcuts]]` entries are defined, the default set is: `wifi`, `bluetooth`, `caffeine`, `nightlight`, `notification`, `power_profile`.
Set `shortcuts = []` under `[control_center]` to hide all Home shortcut buttons.

Use `show_shortcut_labels` under `[control_center]` to show or hide the text under each shortcut icon (default `true`). When labels are off, the icons scale with the shortcut cell size, which is useful at narrower Control Center widths.

```toml
[control_center]
show_shortcut_labels = false
```

## Dynamic Shortcuts

Toggle shortcuts show an active/inactive visual state. `power_profile`, `weather`, and `keyboard_layout` display dynamic labels such as the current power profile, temperature, or keyboard layout.

`weather` is available only when `[weather].enabled = true`. `system` is available only when `[system.monitor].enabled = true`. `screen_time` is available only when `[shell].screen_time_enabled = true`.

`screen_recorder` is a built-in shortcut for the shell recorder (`screen-record-toggle`). While a recording is running the tile highlights, switches to a stop icon, and shows elapsed time. `screen_replay` does the same for the built-in replay buffer (`screen-record-replay-toggle`) and needs `gpu-screen-recorder`. Right-click saves the last N seconds without stopping the buffer; if the buffer is not running, right-click opens Screen Record. Record and replay tiles disable each other while the other is running. The official [`noctalia/screen_recorder` plugin](/noctalia/plugins/official-plugins/#screen_recorder) still exposes its own shortcut as `noctalia/screen_recorder:toggle` when enabled.

`tailscale` toggles this machine's Tailscale connection. Right-click opens the Tailscale tab. The tile is disabled when the `tailscale` CLI is not installed. The community plugin's bar widget and panel remain available.

`localsend` toggles nearby sharing. Right-click opens the LocalSend tab. The setting is saved under `[localsend].enabled`.

`phone` opens the Phone tab. The tile highlights when a paired phone is reachable.

`syncthing` opens the Syncthing tab. The tile highlights when the local daemon is running.

`firewall` opens the Firewall tab. The tile highlights when panic mode is on.

`printers` opens the Printers tab. The tile highlights when a printer is printing or has queued jobs.

`cast` opens the Cast tab. The tile highlights when this screen is being shared.

`privacy` opens the Privacy tab. The tile highlights when an app is using the microphone, camera, or screen share.

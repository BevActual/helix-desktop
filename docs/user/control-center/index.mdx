The Control Center is Noctalia's panel for session controls, system status, media, notifications, weather, and service-specific tools. Open it from the control-center bar widget, by right-clicking empty space on a bar, or with IPC:

```sh
noctalia msg panel-toggle control-center
```

Pass a context to jump straight to a tab:

```sh
noctalia msg panel-toggle control-center audio
noctalia msg panel-open control-center system
noctalia msg panel-toggle control-center author/plugin:displays
```

## Sidebar

Set `sidebar` under `[control_center]` for tab navigation when Control Center opens on **Home** (control center widget, bar background click, or `noctalia msg panel-toggle control-center` with no tab name).
Use `"full"` for icons and labels, `"compact"` for icon-only tabs, or `"none"` to hide the sidebar.

Set `sidebar_section` for opens that jump straight to a tab (volume, network, and media bar widgets, or `noctalia msg panel-toggle control-center audio`).

Keyboard navigation uses the global [`[keybinds]`](/noctalia/configuration/shell/#keybinds) actions: `tab_next` / `tab_previous` switch between the sidebar and the active tab body; arrow keys move within the focused pane.

```toml
[control_center]
sidebar = "compact"
# sidebar_section = "compact"  # optional; defaults to the same as sidebar
# width = 700  # full-sidebar width in pixels (600–1200)
# show_shortcut_labels = true  # text under Home shortcut icons
# show_session_button = true   # session-actions button in the Home header
# hidden_tabs = ["monitor", "weather"]  # hide tabs you never use
```

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `sidebar` | string | `"compact"` | Sidebar on Home / general open: `"full"`, `"compact"`, or `"none"` |
| `sidebar_section` | string | `"compact"` | Sidebar when opening straight to a tab: `"full"`, `"compact"`, or `"none"` |
| `width` | int | `700` | Control Center width in pixels (`600`–`1200`). This is the full-sidebar width; the compact and no-sidebar modes scale down from it. |
| `show_shortcut_labels` | bool | `true` | Show text labels under Home shortcut icons. When `false`, shortcuts are icon-only and glyphs scale with cell size. |
| `show_session_button` | bool | `true` | Show the session-actions button in the Home tab header. |
| `hidden_tabs` | array | `[]` | Tab [context IDs](#sidebar-tabs) to hide from the Control Center. Empty shows every available tab. Editable from **Settings → Control Center**. The Home tab cannot be hidden. |

The full sidebar shows group captions: **Look** (appearance, wallpaper, templates, bar), **Status** (media, audio, weather, and the other live pages), then **Setup** (desktop, dock, launcher, and the other setup pages). Compact mode uses separators between those groups instead of captions.

Plugin Control Center tabs stay in **Status**. User `hidden_tabs` still hide any tab in every group.

### Sidebar Tabs

Use these context IDs with `noctalia msg panel-toggle control-center <context>` or
`noctalia msg panel-open control-center <context>` to open a specific tab.

| Context | Tab | What it shows |
|---------|-----|---------------|
| `home` | Home | User card, media summary, date/time, weather summary, and shortcut buttons |
| `appearance` | Appearance | Theme, palette, fonts, and the rest of appearance settings |
| `wallpaper` | Wallpaper | Library, Wallhaven, and file picker for applying wallpapers. Header gear opens folders, fill mode, automation, and Wallhaven API settings. |
| `templates` | Templates | Color templates and community palettes |
| `bar` | Bar | Bar layout, widgets, and per-monitor bar overrides. Widget add and inspector sheets stay in Control Center. |
| `media` | Media | MPRIS players, playback controls, and artwork. Header gear opens player blacklist settings. |
| `audio` | Audio | Output/input volume, devices, and streams. Header gear opens sound and overdrive settings. |
| `monitor` | Monitor | Per-display brightness plus, on niri, resolution, refresh rate, scale, rotation, VRR, and arrangement. Header gear opens brightness service settings. |
| `system` | System | Distro/kernel, hardware summary, uptime, CPU/RAM/GPU/network graphs, and resource details. Header gear opens battery warnings and system monitor settings. |
| `power` | Power | Battery charge and status, power profiles, battery health, and connected-device battery levels. Header gear opens session panel and idle settings. |
| `network` | Network | Wi-Fi state, connection status, cellular controls, known wireless controls, and NetworkManager-backed actions |
| `bluetooth` | Bluetooth | Adapter power, discoverability, paired devices, connection controls, and pairing flows |
| `weather` | Weather | Current conditions and forecast, with location and units on the live view. Header gear opens night-light settings. |
| `calendar` | Calendar | Month view and configured calendar account events. Header gear opens calendar format settings. |
| `notifications` | Notifications | Notification history, Do Not Disturb, and notification cleanup. Header gear opens daemon, toast, history, and filter settings. |
| `screen-time` | Screen Time | Foreground app usage totals and charts. The enable toggle is on the live view when tracking is off; header gear opens reset. |
| `desktop` | Desktop | Desktop clock, widgets, and desktop behavior |
| `dock` | Dock | Dock placement and behavior |
| `panels` | Panels | Shared panel placement and chrome |
| `launcher` | Launcher | Launcher appearance and providers |
| `control-center` | Control Center | Control Center sidebar, width, shortcuts, and hidden tabs |
| `osd` | OSD | On-screen display volume and brightness popups |
| `screenshot` | Screenshot | Screenshot capture, annotation, and output |
| `shell` | Shell | Shell-wide options, greeter sync, and miscellaneous chrome |
| `keybinds` | Keybinds | In-shell navigation chords, plus niri compositor shortcuts when running on niri |
| `security` | Security | Lock screen and authentication |
| `hooks` | Hooks | Startup and event hooks |
| `niri` | Niri | niri-specific options. Shown only in a niri session. |
| `plugins` | Plugins | Installed plugins and the in-panel plugin store |

`niri` is listed only in a niri session. The Weather, System, Power, and Screen Time tabs stay available so you can turn those features on from the tab itself.

Enabled plugins that declare a `[[control_center_tab]]` are the same kind of sidebar entry as the built-in pages:
they appear in **Status**, each with an id. Built-in ids stay short (`monitor`, `audio`); plugin tabs use the full entry id
(`author/plugin:entry`). Hide any of them except Home via `hidden_tabs` or **Control Center → Control Center**.
See [Control Center tabs](/noctalia/plugins/development/manifest/#control-center-tabs).

Any tab except Home can also be hidden manually with [`hidden_tabs`](#sidebar) (use the context ID, e.g. `"monitor"`). Hidden tabs drop from both the sidebar and keyboard navigation.

## Home

The Home tab is the default Control Center landing view. It combines frequently checked status with a compact shortcut grid.

Click the avatar in the user card to pick a custom image. Noctalia saves the selected path as `[shell].avatar_path`.

When AccountsService is available, Noctalia also writes the selected avatar to `org.freedesktop.Accounts` as your user's `IconFile`. That is what Noctalia Greeter reads for the login user list. On distros where this is not enabled by default, install and enable **accountsservice** (usually the `accounts-daemon` service) if you want the same avatar in both the shell and the greeter.

The shortcut buttons are configured separately; see [Control Center shortcuts](/noctalia/control-center/shortcuts/).

Set `show_session_button = false` under `[control_center]` to hide the session-actions button in the Home tab header. This does not affect Home shortcuts configured with `type = "session"` or session widgets on the bar.

## Wallpaper

The Wallpaper tab is the same picker used by the dedicated wallpaper panel: a thumbnail grid from your configured folders, Wallhaven search, and a folder button to choose any image. Select a monitor (or **ALL**), then click a tile to apply it. Favorites, fill color, and theme-from-wallpaper controls stay on the picker.

Header gear opens wallpaper settings: fill mode, directories, per-monitor folders, automation, and the Wallhaven API key. `noctalia msg settings-toggle wallpaper` opens that settings view. The floating wallpaper panel remains available from the bar widget and `noctalia msg panel-toggle wallpaper`.

## Media

The Media tab shows active MPRIS players and exposes playback controls independent of any bar media widget. It is useful when multiple players are running or when artwork and track metadata need more room than a bar capsule can provide.

## Audio

The Audio tab groups PipeWire output, input, device, and stream controls. Use it for volume changes, muting, selecting devices, and inspecting application streams without opening an external mixer.

## Monitor

The Monitor tab lists connected displays. Brightness sliders appear when Noctalia has a writable backlight (including DDC/CI when that is enabled). On niri, each display also gets resolution, refresh rate, scale, rotation, and optional VRR controls, plus a visual arrangement map when two or more outputs are enabled.

niri only keeps the cursor path between **adjacent, non-overlapping** outputs. A layout change that overlaps another display is rejected and niri auto-places that output to the far right, which jumps windows with it. The Monitor tab pins every enabled output's position on each change so niri does not auto-place the ones you did not move.

Drag a display to another side. While two displays already share an edge, the arrows slide the selected one along that seam (and magnet to top, center, or bottom). Hold **Ctrl** for an 8px nudge and **Shift** for 1px. Left/right still swap sides when the displays are stacked, and up/down swap sides when they sit next to each other. Pick **Relative to** when three or more are on.

Live niri changes apply through compositor IPC. Use the header **Save to niri** button to write the current layout (mode, scale, transform, position, VRR, off) to `noctalia-outputs.kdl` and include it from `config.kdl`. niri reloads that file on its own, so the layout survives compositor restarts. The header refresh button re-reads the current output state (and re-runs DDC/CI detect when that backend is enabled).

## System

The System tab summarizes the machine and live resource usage. It shows distribution/kernel details, board/CPU/GPU information, uptime, install age, load averages, memory and swap, and graphs driven by the shared system monitor service.

System monitor sampling is configured globally under `[system.monitor]`; see [System monitor](/noctalia/services/system-monitor/).

## Network

The Network tab uses the configured network backend to show wireless state and connection details. It is the destination for Wi-Fi shortcuts and network-related right-click actions.

The current connection line lists the IPv4 address, signal strength, radio band, and external IP. The band (`2.4 GHz`, `5 GHz`, `6 GHz`, or `60 GHz`) is shown only when the backend reports the connection frequency: NetworkManager and wpa_supplicant do, iwd does not.

### Enterprise Wi-Fi (802.1X)

Clicking a WPA2/WPA3-Enterprise network opens a credential form instead of the pre-shared-key field: EAP method (PEAP or TTLS), inner authentication, identity, anonymous identity, server domain suffix, and CA certificate path. The password field below the form is the one used for the EAP login.

PEAP accepts MSCHAPv2 only, so the inner dropdown is pinned and disabled while PEAP is selected; TTLS also allows PAP, MSCHAP, and CHAP. Leaving the CA certificate path empty trusts the system CA store; a path must be absolute and pins that file instead of the system store. The server domain suffix is the RADIUS server name suffix your organization publishes, and is optional.

Enterprise networks are recognized on the NetworkManager backend only; the wpa_supplicant and iwd backends still show the pre-shared-key prompt for them, which an 802.1X network cannot accept. Certificate-based EAP-TLS, including WPA3-Enterprise 192-bit, is not supported: the form says so instead of writing a profile NetworkManager would reject. Use `nmcli` or another NetworkManager front end for those networks.

### Cellular

When ModemManager reports a modem, the Network tab adds a **Cellular** card with a mobile-data switch and one row per modem showing its operator (or hardware name), state, access technology (`5G`, `LTE`, `HSPA+`, ...), and signal percentage. The card disappears again when ModemManager stops or the modem is unplugged.

The switch follows GNOME's mobile-data semantics: with a saved NetworkManager `gsm` profile it turns the data connection on and off and leaves the modem registered on the network; with no such profile it powers the modem radio itself. Turning it on can take several seconds while the modem enables, searches, and registers, and the switch holds the requested position until the change lands.

Cellular needs ModemManager running (`org.freedesktop.ModemManager1`) and, for mobile data, a `gsm` connection profile created with `nmcli` or another NetworkManager front end. Noctalia does not create or edit cellular profiles.

## Bluetooth

The Bluetooth tab shows adapter power state, paired devices, and connection controls. It is backed by Noctalia's Bluetooth service and agent.

## Weather

The Weather tab expands the Home weather summary into current conditions and forecast detail. Location and units stay on the live view under the forecast. Night-light stays behind the header gear.

Weather configuration is documented under [Weather](/noctalia/services/weather/).

## Calendar

The Calendar tab shows the month view and events from configured calendar accounts. Calendar accounts and sync behavior are documented under [Calendar](/noctalia/services/calendar/).

Right-click a day to launch the application registered for the `text/calendar` MIME type. The Calendar panel closes
after a successful launch.

`[control_center.calendar]` holds how the tab is drawn; `[calendar]` holds whether events are synced and the shared event date and time formats.

```toml
[control_center.calendar]
show_events_card  = true
show_week_numbers = false       # ISO 8601 week numbers in the month grid
```

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `show_events_card` | bool | `true` | Show the event list beside the month grid. Also toggled from the calendar button in the tab header. |
| `show_week_numbers` | bool | `false` | Show a column of ISO 8601 week numbers to the left of the month grid, separated from it by a divider. Each row is numbered by the week its Thursday falls in. |

The shared `event_date_format` and `event_time_format` options are documented under [Calendar](/noctalia/services/calendar/).
Week numbers are a decoration of the month grid, so they work with `[calendar].enabled = false` and no accounts configured.

## Notifications

The Notifications tab shows notification history and notification actions, including Do Not Disturb. Notification daemon and history behavior are documented under [Notifications](/noctalia/services/notifications/).

## Screen Time

The Screen Time tab shows how long each application was in the foreground today. Noctalia tracks focus using the active `zwlr_foreign_toplevel` window, pauses tracking while its session lock is active, and stores daily totals under `$XDG_STATE_HOME/noctalia/screen_time.json` (about 14 days retained).

When tracking is off, the tab shows a disabled banner with the enable toggle on that same live view.

- **Range** toggle: today (hourly chart), last 3 days, or last 14 days (daily bars)
- **Total** time for the selected range, with a stacked bar chart (hourly or per-day)
- **Chart legend** as a horizontal row under the chart (chart colors only; app list uses neutral bars)
- **Most used** apps with icons, usage bars, and duration for the selected range

Open it from the control center sidebar (`screen-time` context) or add a Home shortcut with `type = "screen_time"`.

Reset stored history from the Screen Time tab header gear (**Screen Time** settings) or **System → Screen Time → Reset Screen Time Data**. That clears `screen_time.json` while Noctalia is running.

## Settings

Settings pages are Control Center tabs. Appearance, Wallpaper, Templates, and Bar sit under **Look**. Live status pages sit under **Status**. Desktop, dock, launcher, plugins, and the other setup pages sit under **Setup**.

Domain options that belong with a live view are on that tab: the wallpaper picker on Wallpaper (header gear for folders and Wallhaven), location and units on Weather, the enable toggle on Screen Time, and header gear on Notifications, Power, System, Calendar, Audio, Monitor, Media, Bar, and Screen Time for the longer forms.

Each settings page is searchable from the sidebar field above Home (or from the header when the sidebar is hidden). An empty query keeps that page’s filter. A non-empty query searches the whole settings registry (section headers still appear on matches) and opens Appearance if you were on Home or another non-settings page.

The plugin store, session/idle editors, notification filters, calendar accounts, community templates, and bar widget inspectors open as sheets in Control Center. The header Advanced toggle shows advanced settings. The ⋮ menu on a settings page exports config and saves a support report.

Open Appearance with `noctalia msg panel-toggle control-center settings`, the Home gear, or `noctalia msg settings-toggle`. Pass a section to land on that page, for example `noctalia msg settings-toggle bar` or `noctalia msg settings-toggle location` (Weather tab, settings view). `settings-toggle` without a section still lands on Appearance.

The Niri page is shown only when the session is running under niri.

## Power

The Power tab consolidates battery and power-management status, backed by UPower and `power-profiles-daemon`:

- **Battery** - charge percentage, charging/discharging state, time remaining (or time until full), and current draw in watts
- **Power Profile** - a selector for the profiles your machine exposes (power-saver, balanced, performance); switching here is equivalent to the Home shortcut and bar widget
- **Battery Health** - current full-charge capacity as a percentage of the original design capacity
- **Connected Devices** - battery levels for peripherals such as Bluetooth mice, keyboards, and headsets

Sections appear only when their data is available: the battery and health sections require a system battery, the profile selector requires `power-profiles-daemon`, and the connected-devices section appears when peripherals report a battery. The tab itself is hidden on systems where neither UPower nor `power-profiles-daemon` is running.

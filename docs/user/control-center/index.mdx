Control Center opens as a quick menu for sound, brightness, Wi-Fi, Bluetooth,
power, media, capture and phone controls. Detailed preferences open **Helix
Settings**, the GTK4/libadwaita application. The old embedded Settings editors
have been retired, including their advanced plugin, widget, hook and Niri forms.
Existing configuration remains active.

```sh
noctalia msg panel-toggle control-center
noctalia msg panel-toggle control-center home
noctalia msg settings-toggle appearance
noctalia msg settings-toggle control-center
helix-settings --page network
```

Settings commands activate the existing Settings window or open a new one. The
Control Center closes when navigating to Settings. The `noctalia` commands and
existing configuration paths remain supported.

## Detailed preferences

Helix Settings provides Appearance, Desktop & Dock, Notifications, Accessibility,
Sound, Network, Bluetooth, Privacy & Security, System and About. Desktop-only
preferences appear when the Helix desktop is available; portable device pages can
operate on other Linux desktops.

Older settings contexts route to the corresponding native page: `theme`,
`wallpaper`, `icons` and `templates` open Appearance; `bar`, `dock`, `launcher`,
`control-center`, `plugins`, `hooks` and `niri` open Desktop & Dock. Unavailable
advanced editors are identified in Settings. Their replacements are still being
built; they do not fall back to an old editor.

## Quick controls and shell surfaces

Direct contexts for live surfaces remain available, including `audio`, `network`,
`bluetooth`, `notifications`, `media`, `capture`, `clipboard`, `phone`, `calendar`
and `weather`. Their settings buttons launch Helix Settings. Dedicated Settings
and customization tabs have been removed from the shell sidebar.

```sh
noctalia msg panel-toggle control-center audio
noctalia msg panel-open control-center capture
noctalia msg panel-toggle control-center clipboard
```

## Control Center preferences

Settings → Desktop & Dock → Control Center configures placement, size, sidebar
style, session actions and visible live pages. Home always remains available.
Extension visibility is preserved when changing built-in page visibility.
Quick Shortcuts provides add, size, reorder, remove and reset controls. Saved
extension shortcuts remain editable; new extension shortcut discovery is pending.

```toml
[control_center]
sidebar = "compact"
# sidebar_section = "compact"
# width = 700
# height = 700
# show_session_button = true
# hidden_tabs = ["monitor", "weather"]
```

Home uses the quick-menu layout and has no sidebar. Sidebar preferences apply to
remaining shell tool pages. Essential actions are visible without hover; keyboard
navigation uses Tab and the configured shell navigation keys.

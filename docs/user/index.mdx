Helix is a niri-first desktop: **greetd → helix-greeter → helix-niri + Helix Shell**. This tree holds the session shell, the greeter (`greeter/`), the compositor (`compositor/`), the apps (Settings, Mobius, Software, System Monitor) and the desktop service. **Fedora + helix-niri are the sole supported product surface.**

If you are setting up Helix for the first time, start with [Installation](/helix/getting-started/installation/), then [Running Helix](/helix/getting-started/running-the-shell/) for compositor startup and keybind setup. Once the shell is installed, [How configuration works](/helix/configuration/) explains where settings live and which file wins when the GUI and your config both set the same option.

:::caution[Some of these pages are being rewritten]
Helix moved from a native, TOML-configured shell to Tauri apps managed through Settings. Pages that describe `[bar.*]`, widget, dock and
shell options from the previous shell no longer apply and are being replaced. Prefer **Settings** for anything you can set there.
:::

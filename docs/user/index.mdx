Helix is a niri-first desktop: **greetd → helix-greeter → helix-niri + Helix Shell**. This tree holds Helix Shell, the greeter (`greeter/`), and the compositor (`compositor/`), with Control Center, first-party services, and a configuration model built for that desktop. The command and config paths stay `helix-shell`. **Fedora + helix-niri are the sole supported product surface.**

If you are setting up Helix for the first time, start with [Installation](/helix/getting-started/installation/), then [Running Helix](/helix/getting-started/running-the-shell/) for compositor startup and keybind setup. Once the shell is installed, [How configuration works](/helix/configuration/) explains where settings live and which file wins when the GUI and your config both set the same option.

:::caution[Coming from Helix v4?]
- Helix Shell (and Helix v5) install separately and do not replace v4.
- v4 settings are not migrated, but both versions can coexist on most distributions.
- Update any compositor keybinds that launch `helix-shell` commands.
:::

Helix is built from the [Helix Desktop source repository](https://github.com/BevActual/helix-desktop). Fedora with helix-niri is the
supported target. Packages for other distributions are not provided.

## Build

Install the build dependencies, then build the workspace. The package list, profiles and optional pieces are in
[BUILDING.md](https://github.com/BevActual/helix-desktop/blob/main/BUILDING.md).

```bash
git clone https://github.com/BevActual/helix-desktop.git
cd helix-desktop
just build release
```

The compositor is a separate workspace:

```bash
cd compositor && cargo build --release
```

## Install

There are two ways to install, depending on whether you want Helix for one user from a checkout or on the whole system.

For yourself, from a checkout (no root needed; it links the build tree and does not restart a running shell):

```bash
tools/switch-shell.sh install
```

For the system, under a prefix (this is what a package does):

```bash
just install            # /usr/local; use `just install /usr` for another prefix
```

`just install` puts the desktop service, assistant, inference service, the session shell, the greeter, Settings, Mobius, Software and
System Monitor under the prefix, with their systemd user units, D-Bus activation, polkit policy, desktop entries and icons. Units are
installed disabled; enable the ones you want per user, for example
`systemctl --user enable --now helix-shell-strut helix-shell-bar helix-shell-panels`.

The login screen's greetd configuration is written by `tools/install-greeter.sh` and the compositor is installed with
`tools/install-trusted-niri.sh`; neither is part of `just install`. See [Running Helix](/helix/getting-started/running-the-shell/) to
start a session.

## Update or remove

```bash
git pull
just build release
tools/switch-shell.sh install   # or: just install
```

`just uninstall` removes what `just install` put under the prefix. Your configuration and state stay under `~/.config/helix`,
`~/.local/state/helix` and `~/.local/share/helix`; see [Uninstall](/helix/getting-started/uninstall/) before removing them.

Report issues in the [Helix issue tracker](https://github.com/BevActual/helix-desktop/issues).

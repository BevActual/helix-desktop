Helix is built from the [Helix Desktop source repository](https://github.com/BevActual/helix-desktop). Fedora with helix-niri is the
supported target. Packages for other distributions are not provided.

## Build

Install the build dependencies, then build the workspace. The package list, profiles and optional pieces are in
[BUILDING.md](https://github.com/BevActual/helix-desktop/blob/main/BUILDING.md).

```bash
git clone https://github.com/BevActual/helix-desktop.git
cd helix-desktop
just build release
```

The compositor is a separate workspace:

```bash
cd compositor && cargo build --release
```

## Install

Install the session shell and apps for your user (no root needed):

```bash
tools/switch-shell.sh install
```

Install the system services (desktop service, assistant, inference service, systemd user units, D-Bus activation, polkit policy):

```bash
just install            # /usr/local; use `just install /usr` for another prefix
```

The login screen is installed with `tools/install-greeter.sh` and the compositor with `tools/install-trusted-niri.sh`. See
[Running Helix](/helix/getting-started/running-the-shell/) to start a session.

## Update or remove

```bash
git pull
just build release
tools/switch-shell.sh install
just install
```

`just uninstall` removes what `just install` put under the prefix. Your configuration and state stay under `~/.config/helix`,
`~/.local/state/helix` and `~/.local/share/helix`; see [Uninstall](/helix/getting-started/uninstall/) before removing them.

Report issues in the [Helix issue tracker](https://github.com/BevActual/helix-desktop/issues).

Helix Shell is currently distributed from the [Helix Shell source repository](https://github.com/BevActual/helix-shell). Install from this repository to get Helix features.

The installed executable, desktop entry, and configuration paths still use `helix-shell` for compatibility. If upstream Helix is also installed, check which `helix-shell` executable your `PATH` selects before starting a session. The two builds use the same configuration and runtime paths.

## Build from source

Install the build dependencies for your distribution from [BUILDING.md](https://github.com/BevActual/helix-shell/blob/main/BUILDING.md). You also need a Wayland compositor, fonts, and a running PipeWire daemon for audio features. Optional runtime services are listed in [PACKAGING.md](https://github.com/BevActual/helix-shell/blob/main/PACKAGING.md).

```bash
git clone https://github.com/BevActual/helix-shell.git
cd helix-shell
just configure release "$HOME/.local"
just build release
just install release
```

This installs the shell and its required assets under `~/.local`. Ensure `~/.local/bin` is on your `PATH`, then use `command -v helix` to check which build will start. To try the executable directly, run `~/.local/bin/helix --version`. The command name in the version output remains `helix-shell`.

Start the shell through your [compositor's startup configuration](/helix/getting-started/running-the-shell/). The intended compositor is in-tree at `compositor/` (build with `cd compositor && cargo build --release`); stock niri and other supported Wayland compositors can also run the shell. The login greeter is in-tree at `greeter/` (`cargo build -p helix-greeter`).

## Update or remove

From the Helix Shell checkout, update and reinstall with:

```bash
git pull
just build release
just install release
```

To remove files installed by this build, run `just uninstall release` from the same checkout and build directory. Your personal configuration and state remain under the `helix-shell` XDG directories; see [Uninstall](/helix/getting-started/uninstall/) before removing them.

For build options, troubleshooting, and system-wide installation, see [BUILDING.md](https://github.com/BevActual/helix-shell/blob/main/BUILDING.md). Report Helix Shell issues in the [Helix issue tracker](https://github.com/BevActual/helix-shell/issues).

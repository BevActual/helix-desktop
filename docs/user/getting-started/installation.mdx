Helix Shell is currently distributed from the [Helix Shell source repository](https://github.com/BevActual/helix-shell). Distribution packages named `noctalia` generally contain [upstream Noctalia](https://github.com/noctalia-dev/noctalia), not this Helix fork. Install from this repository to get Helix features.

The installed executable, desktop entry, and configuration paths still use `noctalia` for compatibility. If upstream Noctalia is also installed, check which `noctalia` executable your `PATH` selects before starting a session. The two builds use the same configuration and runtime paths.

## Build from source

Install the build dependencies for your distribution from [BUILDING.md](https://github.com/BevActual/helix-shell/blob/main/BUILDING.md). You also need a Wayland compositor, fonts, and a running PipeWire daemon for audio features. Optional runtime services are listed in [PACKAGING.md](https://github.com/BevActual/helix-shell/blob/main/PACKAGING.md).

```bash
git clone https://github.com/BevActual/helix-shell.git
cd helix-shell
just configure release "$HOME/.local"
just build release
just install release
```

This installs the shell and its required assets under `~/.local`. Ensure `~/.local/bin` is on your `PATH`, then use `command -v noctalia` to check which build will start. To try the executable directly, run `~/.local/bin/noctalia --version`. The command name in the version output remains `noctalia`.

Start the shell through your [compositor's startup configuration](/noctalia/getting-started/running-the-shell/). [Helix Niri](https://github.com/BevActual/helix-niri) is the intended compositor; stock niri and other supported Wayland compositors can also run the shell. [Helix Greeter](https://github.com/BevActual/helix-greeter) is a separate, optional login component. Build and install those projects using their own instructions.

## Update or remove

From the Helix Shell checkout, update and reinstall with:

```bash
git pull
just build release
just install release
```

To remove files installed by this build, run `just uninstall release` from the same checkout and build directory. Your personal configuration and state remain under the `noctalia` XDG directories; see [Uninstall](/noctalia/getting-started/uninstall/) before removing them.

For build options, troubleshooting, and system-wide installation, see [BUILDING.md](https://github.com/BevActual/helix-shell/blob/main/BUILDING.md). Report Helix Shell issues in the [Helix issue tracker](https://github.com/BevActual/helix-shell/issues).

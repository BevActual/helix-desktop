:::caution
To make Helix's wifi, bluetooth, power-profile, and battery feature available, please ensure the following NixOS options are enabled:
- `networking.networkmanager.enable`
- `hardware.bluetooth.enable`
- `services.power-profiles-daemon.enable` or `services.tuned.enable`
- `services.upower.enable`
:::

## Installation
The `helix-shell` package in nixpkgs is upstream Helix. To build Helix Shell, use the flake in the [Helix Shell repository](https://github.com/BevActual/helix-shell).

Add the Helix repository as an input using your preferred pinning method, then install its package or module. Builds from this input are compiled locally unless you provide a Helix-specific cache.

### Adding the input {#add-input}

<Tabs>
  <TabItem label="flakes">
    Add Helix to your flake inputs:

    ```nix
    # flake.nix
    {
      inputs = {
        helix = {
          url = "github:BevActual/helix-shell";
          inputs.nixpkgs.follows = "nixpkgs"; # optional: use your system's nixpkgs input
        };
      };
    }
    ```

    :::note
    For flakes/tack instructions, we assume you are passing in `inputs` through `specialArgs` or equivalent. 
    :::
  </TabItem>
  <TabItem label="tack">
    Add Helix to your tack inputs:
    ```
    tack add helix github:BevActual/helix-shell
    ```

    Keep the input pinned to a known Helix revision for reproducible builds.

    :::note
    For flakes/tack instructions, we assume you are passing in `inputs` through `specialArgs` or equivalent. 
    :::
  </TabItem>
  <TabItem label="npins">
    Add Helix to your npins sources:
    ```
    npins add github BevActual helix-shell --branch main
    ```

    ```nix
    # configuration.nix
    { pkgs, ... }:
    let
      helix = import (import ./npins).helix-shell {
        inherit pkgs; # optional: use your system's nixpkgs input
      };
    in
      # see installation below
    ```
  </TabItem>
  <TabItem label="tarball">
    Add Helix directly using `builtins.fetchTarball`.
    With pinning:
    ```nix
    # configuration.nix
    { pkgs, ... }:
    let
      helix-src = let
        commit = ""; # replace this with an actual commit id or tag
      in
        fetchTarball {
          url = "https://github.com/BevActual/helix-shell/archive/${commit}.tar.gz";
          sha256 = ""; # replace this with hash from nix build output, or by using `nix-prefetch-url --unpack`
        };
      
      helix = import helix-src {
        inherit pkgs; # optional: use your system's nixpkgs input
      };
    in
      # see installation below
    ```

    Without pinning (not recommended):
    ```nix
    # configuration.nix
    { pkgs, ... }:
    let
      helix-src = fetchTarball "https://github.com/BevActual/helix-shell/archive/main.tar.gz";

      helix = import helix-src {
        inherit pkgs; # optional: use your system's nixpkgs input
      };
    in
      # see installation below
    ```
  </TabItem>
</Tabs>

### Installing the Package {#install-package}

Note that both the Home Manager and Hjem modules install the package for you, so you can omit this step.

<Tabs>
  Add the package to your system packages or equivalent:
  <TabItem label="flakes/tack">
    ```nix
    # configuration.nix
    { inputs, pkgs, ... }:
    {
      environment.systemPackages = [
        inputs.helix.packages.${pkgs.stdenv.hostPlatform.system}.default
      ];
    }
    ```
  </TabItem>
  <TabItem label="npins/tarball">
    ```nix
    # configuration.nix
    let
      # see adding the input above
    in {
      environment.systemPackages = [
        helix.package
      ];
    }
    ```
  </TabItem>
</Tabs>

### Home Manager Module {#home-manager}

The Home Manager module allows you to configure Helix's settings [(that you would otherwise put in `~/.config/helix/`)](/helix/configuration/) using nix instead of toml, or allows you to link an existing toml file. It is optional.

<Tabs>
  <TabItem label="flakes/tack">
    ```nix
    { inputs, ... }:
    {
      home-manager.users.drfoobar = {
        imports = [
          inputs.helix.homeModules.default
        ];

        programs.helix = {
          enable = true;

          settings = { # This may also be a string or path to a .toml file.
            theme = {
              mode = "dark";
              source = "builtin";
              builtin = "Catppuccin";
            };

            wallpaper = {
              enabled = true;
              default.path = "/path/to/wallpapers/wallpaper.png";
            };
          };
        };
      };
    }
    ```
  </TabItem>
  <TabItem label="npins/tarball">
    ```nix
    let
      # see adding the input above
    in {
      home-manager.users.drfoobar = {
        imports = [
          helix.homeModule
        ];

        programs.helix = {
          enable = true;

          settings = { # This may also be a string or path to a .toml file.
            theme = {
              mode = "dark";
              source = "builtin";
              builtin = "Catppuccin";
            };

            wallpaper = {
              enabled = true;
              default.path = "/path/to/wallpapers/wallpaper.png";
            };
          };
        };
      };
    }
    ```
  </TabItem>
</Tabs>

### Hjem Module {#hjem}

For those using Hjem instead of Home Manager, a Hjem module is also available.

<Tabs>
  <TabItem label="flakes/tack">
    ```nix
    { inputs, ... }:
    {
      hjem = {
        extraModules = [
          inputs.helix.hjemModules.default
        ];

        users.drfoobar = {
          programs.helix = {
            enable = true;
            
            settings = { ... };
          };
        };
      };
    }
    ```
  </TabItem>
  <TabItem label="npins/tarball">

### NixOS Module {#nixos-module}

The NixOS module installs the package system-wide and can enable some recommended services.

<Tabs>
  <TabItem label="flakes/tack">
    ```nix
    { inputs, ... }:
    {
      imports = [
        inputs.helix.nixosModules.default
      ];
    
      programs.helix = {
        enable = true;
    
        # Enables NetworkManager, Bluetooth, UPower, and a power profile service.
        recommendedServices.enable = true;
      };
    }
    ```
  </TabItem>
  <TabItem label="npins/tarball">
    ```nix
    let
      # see adding the input above
    in {
      imports = [
        helix.nixosModule
      ];
      
      programs.helix = {
        enable = true;
      
        # Enables NetworkManager, Bluetooth, UPower, and a power profile service.
        recommendedServices.enable = true;
      };
    }
    ```
  </TabItem>
</Tabs>

### Systemd Service {#systemd}

Each of the above modules includes a systemd user service for Helix, which can be enabled by setting `programs.helix.systemd.enable = true`.

:::note
When using the service, `launch_apps_as_systemd_services` defaults to on so apps launched from Helix survive a service restart. Turn it off only if you want those apps to die with the shell.
:::

If you installed Helix Shell from this repository, remove it from the same source checkout and build directory.

### Source installation

If you installed with `just install release`, run:

```bash
just uninstall release
```

## Cleaning Up

The shell's personal configuration, state, and cache are separate from installed files. These paths are shared with upstream Helix, so remove them only if you no longer need that data.

### Configuration and Cache

Helix stores its configuration and cache in the standard XDG directories. To remove them:

```bash
rm -rf ~/.local/state/helix
rm -rf ~/.cache/helix
```

### Generated Templates

If you enabled any templates in the **Color Scheme** settings, you will need to manually delete the generated files.

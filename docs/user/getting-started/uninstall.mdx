Remove Helix the way you installed it.

### Packages

```bash
sudo dnf remove helix helix-greeter helix-niri
```

Removing `helix-niri` removes the compositor, which also provides `/usr/bin/niri`. Reinstall Fedora's with `sudo dnf install niri` before you log
out. If you used the Helix login screen, put your greetd configuration back first (`sudo cp /etc/greetd/config.toml.before-helix
/etc/greetd/config.toml`, if you made that copy), otherwise greetd will look for a login screen that is gone and fall back to its text login.
`/etc/niri/config.kdl` is kept if you edited it.

### Source installation

If you installed with `just install release`, run:

```bash
just uninstall release
```

## Cleaning Up

The shell's personal configuration, state, and cache are separate from installed files. Remove them only if you no longer need that data (your settings, chats and Mobius projects are in them).

### Configuration and Cache

Helix stores its configuration and cache in the standard XDG directories. To remove them:

```bash
rm -rf ~/.config/helix ~/.local/state/helix ~/.local/share/helix ~/.cache/helix
```

### Generated Templates

If you enabled any templates in the **Color Scheme** settings, you will need to manually delete the generated files.

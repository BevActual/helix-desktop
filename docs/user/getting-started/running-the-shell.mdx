A Helix session is **greetd → helix-greeter → helix-niri + the shell**. With the greeter installed, you log in on the Helix login
screen and the session starts on its own. Without it, start `niri-session` (or your compositor's session) from any display manager; the
shell's systemd user units come up with the graphical session once they are installed.

## Start after installing the packages

With the RPM packages (see [Installation](/helix/getting-started/installation/)) there is nothing to start by hand: log out and choose the
**Niri** session, or use the Helix login screen if you installed `helix-greeter` and switched greetd to it. The bar, the strut that reserves
space for it, the wallpaper and idle handling start with the session; a restart of one part is the same `systemctl --user restart helix-shell-bar` and so on.

## Install and start from a checkout

```bash
tools/switch-shell.sh install      # links the binaries and units; starts the shell only if it is not already running
tools/switch-shell.sh status       # what is running
```

`install` never restarts a live shell, so it is safe to run while you work.

## Restart parts of the session

The shell is split into small processes, so most changes need only one of them restarted:

```bash
tools/switch-shell.sh restart-panels   # panels and the launcher only; the bar stays up
tools/switch-shell.sh restart-bar      # the bar; windows keep their space
tools/switch-shell.sh restart          # bar and panels
```

`restart-strut` also restarts the process that reserves the top of the screen, which makes windows jump; avoid it with applications
open.

## Settings, apps and agents

Open **Settings** from the bar or the launcher. Appearance, wallpaper, network, Bluetooth, sound, keyboard, dock, power and the
privacy and agent controls are all there. **Mobius** is the AI hub; anything an agent wants to change on your desktop asks for your
approval first, in a dialog the shell draws.

## Compositor

helix-niri is the compositor Helix is built and tested with: `cargo build --release -p niri`, then
`tools/install-trusted-niri.sh`. Its configuration is described under [Compositor](/helix/compositor-settings/).

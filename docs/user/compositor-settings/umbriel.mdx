:::caution[Unsupported product surface]
Helix’s sole supported session is **Fedora + helix-niri**. This page is historical reference only and is not a supported setup. Use [Niri](/helix/compositor-settings/niri/) instead.
:::

Add the following settings to your Umbriel configuration file, usually located at `~/.config/umbriel/config.toml`.
Umbriel's packaged [`examples/config.toml`](the upstream project repository) is a useful reference for the complete configuration. Umbriel also provides dedicated documentation for [configuration](/umbriel/configuration/), [window rules](/umbriel/window-rules/), and [layer rules](/umbriel/layer-rules/).

## Autostart Helix

Add `helix-shell` to the `autostart` array under `[general]`. Preserve any commands that are already in the array:

```toml
[general]
autostart = ["helix"]
```

Umbriel runs these commands once after startup and does not run them again when its configuration is reloaded.

## Compositor Settings

These settings provide rounded windows, consistent borders, and a blurred compositor background:

```toml
[appearance]
prefer_no_csd = true
border_width = 2
corner_radius = 10

[appearance.blur]
enabled = true
optimized = true
passes = 3
radius = 3
noise = 0.02
brightness = 0.9
contrast = 0.9
saturation = 1.1
```

Adjust these values to match your preferred appearance. The full list of options is available in Umbriel's [Appearance](/umbriel/appearance/) and [Animation](/umbriel/animation/) references.

## Window Rules

Settings live in Control Center (a layer-shell panel), so Helix no longer opens an xdg-toplevel that needs a floating window rule. Umbriel still combines matching rules in file order; see Umbriel's [Window Rules](/umbriel/window-rules/) reference for placement, workspace, opacity, blur, and focus options.

A typical global blur rule still applies to other windows:

```toml
# Blur all windows
[[window_rule]]
blur = true
blur_optimized = true
```

## Layer Rules and Blur

Helix publishes blur regions for its layer-shell surfaces when the compositor supports the `ext-background-effects` protocol. Enable blur for the bar, notifications, dock, panels, and OSD with the layer rule from Umbriel's example configuration:

```toml
[[layer_rule]]
match.namespace = "^helix-(bar-[^\"]+|notification|dock|panel|attached-panel|osd)$"
blur = true
blur_ignore_alpha = 0.5
blur_optimized = false
```

The namespace expression targets Helix's standard surfaces without matching unrelated layer-shell clients. `blur_ignore_alpha = 0.5` avoids blurring highly transparent parts of a surface. `blur_optimized = false` makes this rule use the regular blur path instead of the optimized mode configured globally under `[appearance.blur]`.

Layer-surface blur is disabled by default in Umbriel. Inspect active namespaces with:

```sh
umbriel layers
```

For the complete set of layer-rule options, see Umbriel's [Layer Rules](/umbriel/layer-rules/) reference.

## IPC Keybinds

Umbriel can launch Helix IPC commands directly from its `[keybinds]` table. Add these bindings to `~/.config/umbriel/config.toml`:

```toml
[keybinds]
"Mod+Space" = "spawn:helix-panel panel-toggle launcher"
"Mod+S" = "spawn:helix-panel panel-toggle control-center"
"Mod+Comma" = "spawn:helix-panel settings-toggle"
"Alt+Tab" = "spawn:helix-panel window-switcher"
"Mod+Shift+A" = "spawn:helix-panel screenshot-annotate"
"Mod+Ctrl+A" = "spawn:helix-panel annotate"

"XF86AudioRaiseVolume" = "spawn:helix-panel volume-up"
"XF86AudioLowerVolume" = "spawn:helix-panel volume-down"
"XF86AudioMute" = "spawn:helix-panel volume-mute"
"XF86MonBrightnessUp" = "spawn:helix-panel brightness-up"
"XF86MonBrightnessDown" = "spawn:helix-panel brightness-down"
```

`Mod` uses Umbriel's configured modifier from `general.mod_key` and defaults to Super in a native session. See [Keybinds](/umbriel/keybinds/) for more Helix IPC examples and the complete action reference.

## Optional Type to Launch

Helix can open its launcher when you start typing in umbriel's overview.

```toml
[shell]
umbriel_overview_type_to_launch_enabled = true
```

You can also enable this from **Settings → Umbriel → Overview**.

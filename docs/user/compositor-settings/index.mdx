Helix’s sole supported product surface is **Fedora + helix-niri** (in-tree `compositor/`). See the Niri guide for the live setup path.

| Page | Status |
|---|---|
| [Niri](/helix/compositor-settings/niri/) | **Supported** — helix-niri |
| Hyprland, Sway/Scroll, Mango, Labwc, Umbriel, KDE | **Unsupported** — kept as historical notes only |

Do not treat unsupported pages as install guidance. Login remains greetd + helix-greeter; the compositor owns window management; Helix Shell owns layer-shell chrome.

IPC commands let you control Helix from a terminal, a compositor keybind, a script, or a hook.

All commands use this shape:

```sh
helix-panel <command>
```

For example:

```sh
helix-panel dock-toggle
helix-panel volume-up
helix-panel panel-toggle launcher
helix-panel screenshot-region
```

<Aside type="note">
These pages list commands exactly as you run them. The same `helix-panel ...` form is used in terminals, compositor keybinds, hooks, hot-corner commands, and idle command fields.
</Aside>

## Compositor keybinds

A compositor keybind only needs to launch a Helix command. The command part is compositor-agnostic:

```sh
helix-panel panel-toggle launcher
helix-panel panel-toggle control-center
helix-panel settings-toggle
helix-panel volume-up
```

Use your compositor's normal `exec`, `spawn`, or command-binding syntax to run those commands.

## Discovering commands

Not sure what else you can control? You can see all IPC commands via this terminal command:

```bash
helix-panel --help
```

## Using IPC in config

Config command fields run through the shell. Use the canonical IPC CLI when a command needs to call Helix, and compose it with other shell commands when needed:

```toml
[idle.behavior.custom]
timeout = 660
action = "command"
command = "helix-panel session lock && notify-send 'Session locked'"

[hooks]
started = "helix-panel panel-toggle launcher"
```
